- the upstream `README.md` states that the project is licensed under **GPL-3.0**;
- the upstream `package.json` declares **MIT**;
- no root `LICENSE` file was present in the upstream repository snapshot reviewed for this fork.

Because the code in this repository includes substantial upstream-derived material, this fork does **not** attempt to unilaterally relicense that upstream code or pretend that the ambiguity has been resolved.

Accordingly:

- `package.json` points to this file instead of declaring MIT or GPL;
- the README does not advertise a definitive software license;
- [NOTICE.md](./NOTICE.md) preserves upstream attribution and describes the derivative relationship.
